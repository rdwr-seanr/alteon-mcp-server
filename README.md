## About

This repository contains a production-ready MCP server that enables AI-powered monitoring, topology discovery, and configuration validation for Alteon ADC devices.

### Features

- **18 Professional Tools** across 4 phases
- **100% Test Coverage** (18/18 tests passing)
- **TypeScript** with full type safety
- **AI Integration** via Model Context Protocol
- **Production Ready** with comprehensive documentation

### Installation

```bash
cd alteon-mcp-server
npm install
npm run build
npm test
```

For detailed setup and usage instructions, see the [main README](alteon-mcp-server/README.md).
